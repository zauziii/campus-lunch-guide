# Campus Lunch Guide

A simple guide to today's meat and fish dishes at UniCafe restaurants across Helsinki campuses, with Chinese translations.

## How it works

- Fetches UniCafe menu data in the browser each time the page opens.
- Uses the Helsinki date, and refreshes every 15 minutes while the page is open.
- Groups restaurants by campus and shows meat and fish in separate columns.
- Translates dish names into Chinese and lets you show Finnish originals.

Menu data comes from https://menu.unicafe.fi/. Public dish names are sent to the MyMemory translation service. Translation can be unavailable or inaccurate. Classification uses menu labels, ingredients, and keywords, so it can miss or misclassify dishes. Check the official information for allergens and dietary needs. This independent project is not affiliated with UniCafe.
